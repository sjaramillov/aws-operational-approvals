# Base técnica conservada

Los documentos de esta carpeta conservan la base de ingeniería del proyecto y complementan la documentación actual.

| Base | Uso |
|---|---|
| `PRODUCT.md` | Usuarios, propósito, límites y principios |
| `DESIGN.md` | Sistema visual histórico; la extracción modifica nombre, icono y paleta |
| `commercial-candidate.md` | Invariantes y ciclo de vida propuesto del candidato |
| `backend.md` | Entrypoints, contratos y persistencia |
| `frontend.md` | Modos demo/HTTP, PKCE y contrato de cliente |
| `threat-model.md` | Amenazas, mitigaciones y evidencia requerida |

Los textos de operación en estas bases describen un diseño histórico que dependía de guardrails externos. No prueban un despliegue actual ni son una instrucción para usar la cuenta original. Para ejecutar localmente, usa [el runbook actual](../runbook.md). La correspondencia de origen se registra en [el manifiesto](../source-manifest.json).
